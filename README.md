# Cashflow — Draft 01

A mobile-first personal cash-flow manager prototype built with Next.js.

## Current draft

- Dashboard
- Income / expense / transfer quick add
- Accounts placeholder
- Client receivables
- Friends' loans
- Analytics placeholder
- Credit-card-aware transaction structure
- PWA manifest for iPhone Home Screen installation

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000
